# ByteKibble 1.2.0 (47) · MU Labs

Apple silicon（arm64）测试版，Developer ID 签名，尚未 Apple 公证。

## 应用更新

- 接入 Sparkle 2.9.6。点击底部版本号，可检查更新、开启或关闭自动检查，并访问 GitHub。
- 自动检查默认开启，安装仍需用户确认；不启用无人值守安装，不发送系统配置统计。
- 更新包通过 EdDSA 签名验证，再进行解压、替换和重新启动。
- 更新检查联系 GitHub，不向更新器传入订阅链接、令牌、流量读数或重置日期。
- 测试版使用独立 preview 更新源。未来正式版应使用单独更新源，不能仅凭 GitHub 的 prerelease 标签区分。

## 旧用户如何升级

build 46 及更早版本没有更新器，需要手动安装一次带更新器的版本。
后续发布必须同时上传签名应用包，并在包可下载后更新 appcast；只创建 GitHub Release 不会触发提醒。
请将应用移入“应用程序”，不要长期运行 DMG 内的只读副本。

## 下载

- `-installer.zip`：解压得到 DMG，保留安装器自定义图标。
- `.dmg`：拖拽安装包。
- `-arm64.zip`：应用本体，也是 Sparkle 使用的签名更新包。
- `SHA256SUMS.txt`：下载完整性校验。

最低 macOS 13；本机验收环境为 macOS 27，不代表所有旧系统均已验证。
