ByteKibble은 **잔여 데이터, 사용량, 구독 만료일 및 초기화 알림**을 확인하는 macOS 메뉴 막대 앱입니다. 지원되는 Clash 계열 클라이언트와 SNTP의 구독을 자동으로 찾고, Quantumult / Quantumult X와 Surge에서 사용하는 HTTPS 구독 링크를 직접 추가할 수 있으며 Shadowsocks SIP008 사용량 필드를 읽습니다. 표시되는 정보는 제공업체가 반환하는 데이터에 따라 달라집니다. 자세한 조건은 아래 호환 범위를 확인하세요.

> **1.2.0 (49) 프리릴리스**: 앱 소스, 첫 실행 환영 화면, Apple silicon (arm64) 패키지를 제공합니다. Developer ID로 서명했지만 **Apple 공증은 받지 않았습니다**. [다운로드 및 변경 사항](https://github.com/mustundead/ByteKibble/releases/tag/v1.2.0-build49). `preview/`의 이미지는 과거 버전입니다.

**앱 내 업데이트(build 47부터):** 하단 버전 번호에서 업데이트를 확인하거나 자동 확인을 끌 수 있습니다. 설치에는 사용자 확인이 필요합니다. build 46 이하는 먼저 한 번 수동으로 업데이트해야 합니다. 업데이트 확인은 GitHub에 연결하지만 구독 링크나 사용량은 전송하지 않습니다. 미리 보기 버전은 별도 업데이트 피드를 사용합니다.

## 주요 기능

- **메뉴 막대에서 잔여량 확인**: 숫자는 남은 데이터양, 원형 그래프는 남은 비율을 표시합니다. 클라이언트에 초기화 정보가 있으면 카운트다운도 표시합니다.
- **하나의 패널에 모은 상세 정보**: 요금제 이름, 남은 양/사용량/전체 한도, 업로드와 다운로드, 예상 초기화 날짜, 구독 만료일, 출처와 업데이트 시각을 확인합니다.
- **여러 구독 전환**: 읽을 수 있는 클라이언트 설정에서 구독을 찾거나 HTTPS 구독 링크를 직접 추가해 각각의 사용량을 확인합니다.
- **필요할 때만 경고**: 잔여량이 20% 미만이면 주황색, 10% 미만이면 빨간색으로 표시합니다. 부족하거나 소진된 상태는 글자로도 안내합니다.
- **macOS에 맞는 사용 경험**: SwiftUI, 라이트/다크 모드, 고정 폭 숫자, 동작 줄이기 지원, 켜짐/꺼짐이 명확한 로그인 시 자동 실행 표시.
- **5개 인터페이스 언어**: 중국어 간체, 중국어 번체, 영어, 한국어, 일본어.

ByteKibble은 **프록시 클라이언트, VPN, 속도 측정 도구 또는 앱별 네트워크 사용량 측정기가 아닙니다**. Clash/Mihomo 대신 트래픽을 라우팅하거나 제공업체의 데이터 한도를 변경하지 않습니다.

## 색상과 진행률 읽기

| 남은 데이터 비율 | 표시 | 의미 |
| --- | --- | --- |
| 20% 이상 | 화면 모드에 맞는 검정/흰색 기본 색상 | 정상 |
| 10% 이상, 20% 미만 | 주황색 | 잔여량 부족 |
| 10% 미만 | 빨간색 | 잔여량이 매우 적거나 소진됨 |

메뉴 막대의 원형 그래프는 **남은 비율**을, 상세 카드의 가로 막대는 “사용량” 백분율과 같은 **사용한 비율**을 나타냅니다. 경고색은 데이터 잔여량의 위험 수준만 뜻하며 요금제 등급, 연결 상태, 자동 실행 설정을 나타내지 않습니다. 초기화 날짜가 가까워지는 것 자체는 오류가 아닙니다.

## 데이터 출처

**현재 호환 범위(build 49):** 자동 감지와 수동 가져오기는 별개입니다. Stash, Clash, Surge, Hiddify, Loon, sing-box의 지원되는 가져오기 링크를 붙여 넣으면 Mac에서 HTTPS 구독 URL만 추출합니다. Quantumult / Quantumult X는 원본 HTTPS 구독을 직접 추가할 수 있습니다. 제공업체가 `Subscription-Userinfo` 또는 지원되는 Shadowsocks SIP008 사용량 필드를 반환해야 합니다. 해당 클라이언트의 자동 감지를 추가한 것은 아니며, 모든 클라이언트·제공업체의 실기기 연동 검증을 완료하지는 않았습니다. [지원 형식 및 공식 근거](docs/client-compatibility.md).

| 출처／클라이언트 | 읽기 또는 가져오기 방식 | 참고 |
| --- | --- | --- |
| Clash Verge / Clash Verge Rev | 로컬 `profiles.yaml`의 구독 링크 | 사용량은 제공업체에 조회합니다 |
| ClashX / ClashX Meta / ClashX Pro | 클라이언트 환경설정의 구독 링크 | 읽을 수 있는 형식으로 저장되어 있어야 합니다 |
| SNTP | 구독 링크, 요금제와 사용량 캐시, 클라이언트가 보고한 초기화까지의 일수 | 캐시에 신뢰할 수 있는 원래 업데이트 시각이 없을 수 있습니다 |
| 직접 추가 | 붙여 넣은 HTTPS 구독 링크 | 제공업체가 해석 가능한 사용량 정보를 반환해야 합니다 |
| Stash / Clash | HTTPS 또는 지원되는 `install-config` 링크를 직접 추가 | Stash는 지정된 `link.stash.ws` 설정 링크 형식도 지원 |
| Surge | HTTPS, `#!MANAGED-CONFIG` 첫 줄 또는 설정 가져오기 링크 | 모듈이나 설정 내용을 실행하지 않음 |
| Hiddify | HTTPS 또는 지원되는 구독 가져오기 링크 | URL과 토큰을 보존하며 단일 노드는 가져오지 않음 |
| Loon / sing-box | HTTPS 또는 지원되는 구독／원격 설정 링크 | 플러그인, 규칙, 스크립트 및 클라이언트 제어 명령을 실행하지 않음 |
| Quantumult / Quantumult X | 원본 HTTPS 구독을 직접 추가 | 제공업체의 사용량 정보 필요 |
| Shadowsocks SIP008 | HTTPS 응답의 `bytes_used`, `bytes_remaining` | 업로드／다운로드 구분이 없으면 미제공으로 표시 |

단일 `ss://`, `vmess://`, `vless://`, `trojan://` 노드는 잔여량 조회 인터페이스가 아닙니다. 확인되지 않은 Shadowrocket 전용 링크나 일반 VPN 계정 잔액은 지원 범위에 포함하지 않습니다.

최신 사용량은 `subscription-userinfo` 응답 헤더에서 가져오며, 헤더가 없으면 SIP008 JSON의 사용량 필드를 읽습니다. **Mihomo 코어를 사용한다고 자동으로 감지되는 것은 아닙니다**. 자동 감지는 위 표의 저장 형식을 지원합니다. 다른 클라이언트에서는 구독 링크를 직접 추가해 볼 수 있습니다.

ByteKibble이 모든 네트워크 트래픽을 직접 측정하는 것은 아닙니다. 수치는 제공업체나 클라이언트가 반환한 값에 따릅니다. 헤더 누락, 필수 필드 부족, 전체 한도가 0인 경우 또는 조회 실패를 “측정된 잔여량 0”으로 해석하면 안 됩니다. 이전 수치를 볼 때는 출처와 업데이트 시각도 확인하세요.

### 초기화 날짜와 새로 고침

- 초기화 카드를 눌러 다음 날짜를 설정할 수 있습니다. 이 Mac에만 저장되며 직접 설정과 `*`로 구분됩니다. 지우면 구독 정보로 돌아갑니다. 지난 날짜는 만료된 날짜로 표시하고 자동으로 반복하거나 제공업체의 사용량을 초기화하지 않습니다.

- 초기화까지의 일수는 클라이언트가 보고한 값이며 일반 구독 헤더의 표준 필드가 아닙니다. 카운트다운과 **예상 날짜**는 이 일수로 계산하며, 제공업체가 확정한 초기화 시각이 아닙니다. 오래된 캐시는 정확도에 영향을 줄 수 있습니다.
- 정보가 없으면 날짜를 추측하지 않습니다. 구독 만료와 데이터 한도 초기화는 서로 다른 개념입니다.
- 앱 실행 중 주기적으로 갱신하며 직접 새로 고칠 수도 있습니다. 잠자기, 네트워크, 제공업체 응답 때문에 지연될 수 있습니다.
- 직접 연결과 일반적인 로컬 프록시 포트(`7899`, `7890`, `7897`, `6152`)를 시도합니다. 프록시 클라이언트를 실행하거나 시스템 프록시 설정을 변경하지 않습니다.

## 시스템 요구 사항과 설치

**macOS 13 이상**이 필요합니다. 네이티브 Liquid Glass 스타일은 macOS 26 이상에서 사용하며 이전 시스템에서는 호환 스타일을 사용합니다. 프로세서 지원, 서명, 공증 여부는 각 패키지의 릴리스 설명을 확인하세요.

[1.2.0 (49) 릴리스 페이지](https://github.com/mustundead/ByteKibble/releases/tag/v1.2.0-build49)에서 DMG 또는 ZIP을 받으세요. 이전 버전을 종료한 뒤 DMG의 ByteKibble을 Applications로 드래그하거나 ZIP을 풀어 앱을 “응용 프로그램”으로 옮기세요. 디스크 안의 복사본이 아닌 “응용 프로그램”에서 실행하세요. 처음 사용할 때 환영 화면이 표시됩니다.

배포 바이너리는 **Apple silicon (arm64) 전용**이며 Intel 버전은 포함하지 않습니다. 로컬 빌드, 테스트 및 화면 확인은 macOS 27에서 수행했습니다. 최소 배포 대상은 macOS 13이지만 모든 이전 OS에서 실기기 검증을 완료했다는 의미는 아닙니다.

App 아이콘과 오른쪽 아래 열린 상자 배지를 유지하려면 `-installer.zip`을 풀어 DMG를 꺼내세요. DMG를 HTTP로 직접 다운로드하면 사용자 지정 아이콘 메타데이터는 유지되지 않지만 설치 내용은 같습니다. 별도의 `-arm64.zip`에는 앱 자체가 들어 있습니다.

![1.2.0 (43)의 실제 DMG 창](docs/assets/installer-1.2.0.png)

macOS가 실행을 차단하면 먼저 다운로드 출처, 서명, 릴리스 설명을 확인하세요. 파일을 신뢰할 수 있는 경우에만 [Apple의 안내](https://support.apple.com/guide/mac-help/mh40616/mac)에 따라 “시스템 설정 → 개인정보 보호 및 보안”에서 처리하세요. **서명과 공증은 다릅니다.** 설치를 위해 시스템 보안 기능을 끄지 마세요.

지원되는 클라이언트에 구독을 가져오거나 ByteKibble에 HTTPS 링크를 추가하면 됩니다. 앱은 메뉴 막대에서 동작합니다. 로그인 시 자동 실행은 선택 사항이며 잔여량 확인에 필수적이지 않습니다.

## 개인정보 보호와 범위

**분석은 Mac에서 수행하며 구독 링크를 MU Labs나 분석 플랫폼에 업로드하지 않습니다.** 클라이언트 설정 감지, 가져오기 링크 추출 및 사용량 필드 분석에는 클라우드 분석이나 타사 구독 변환 서비스를 사용하지 않습니다. 구독의 스크립트, 규칙, 노드 설정도 실행하지 않습니다.

**로컬 분석이 완전한 오프라인 동작을 의미하지는 않습니다.** 사용량 새로 고침은 구독 제공업체 URL에 요청하며 HTTPS 리디렉션을 따를 수 있습니다. 제공업체에는 요청에 필요한 구독 URL／토큰이 전송됩니다. 로컬 프록시를 사용하면 설정된 경로를 통합니다. 업데이트 확인과 다운로드는 GitHub 및 다운로드 서비스에 연결하지만 업데이트 기능에 구독 URL, 토큰, 사용량을 전달하지 않습니다. 자동 업데이트 확인을 꺼도 사용량 새로 고침은 중지되지 않습니다.

시스템 TLS 인증서 검증을 유지하고 HTTP로의 다운그레이드를 거부합니다. 토큰을 포함할 수 있는 원본 네트워크 오류를 화면에 직접 표시하지 않습니다. 직접 추가한 링크는 로컬 환경설정에 저장되며 **키체인 암호화 저장이 아닙니다**. 장치 침해, 로컬 데이터 접근 또는 백업 유출 시 안전을 보장하지는 않습니다.

자동 감지는 로컬 클라이언트 설정을 읽습니다. 직접 추가한 링크는 ByteKibble의 로컬 환경설정에 저장됩니다. 추가, 삭제, 실행 취소는 앱 자체 목록만 바꾸며 **제공업체의 구독을 수정하거나 해지하지 않습니다**.

구독 URL에 액세스 토큰이 포함될 수 있으므로 비밀번호처럼 관리하세요. 조회는 해당 제공업체로 전송됩니다. 로컬 프록시를 사용하면 요청은 해당 프록시에 설정된 경로로 전달됩니다. ByteKibble에는 자체 트래픽 중계 서버가 없으며 구독 링크를 분석 플랫폼으로 보내지 않습니다.

공개 Issue나 스크린샷에서 구독 URL, 토큰, 계정 정보를 가려 주세요.

## 소스에서 빌드

Swift 도구 모음이 포함된 Xcode를 설치한 뒤 실행하세요.

```bash
git clone https://github.com/mustundead/ByteKibble.git
cd ByteKibble
swift build -c release
```

서드 파티 런타임 의존성은 없습니다. `swift test -j 2`로 테스트하세요. `bash scripts/package-local.sh release`는 호스트 아키텍처의 ad-hoc 서명 앱을 `output/acceptance/`에 생성하며, `actool`이 포함된 Xcode가 필요합니다. 소스 빌드는 배포자의 Developer ID 서명이나 공증을 자동으로 수행하지 않습니다. DMG 생성 방법은 [CHANGELOG](CHANGELOG.md)를 확인하세요.
