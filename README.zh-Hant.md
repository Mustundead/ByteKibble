字節貓糧是一款原生 macOS 選單列訂閱流量工具，用來查看**剩餘流量、已用流量、方案到期資訊與重置提醒**。它可自動探索受支援的 Clash 系用戶端及守候網路（SNTP）訂閱，也可手動加入 Quantumult／Quantumult X、Surge 使用的 HTTPS 訂閱連結，並解析 Shadowsocks SIP008 流量欄位。可顯示的資訊取決於服務商回傳的資料，具體條件請見下方相容性說明。

> **1.2.0（49）測試版**：提供應用程式碼、首次使用歡迎頁及 Apple silicon（arm64）安裝包。已使用 Developer ID 簽署，**尚未經 Apple 公證**。[下載與完整更新說明](https://github.com/mustundead/ByteKibble/releases/tag/v1.2.0-build49)。`preview/` 中的舊截圖為歷史資料。

**App 內更新（build 47 起）**：點擊底部版本號可檢查更新或關閉自動檢查，安裝須由使用者確認。build 46 及更早版本須先手動安裝一次新版。更新檢查會連線至 GitHub，不傳送訂閱連結或流量資料；測試版使用獨立更新來源。

## 一眼看懂流量

- **選單列常駐剩餘量**：數值顯示剩餘流量，實心圓餅圖顯示剩餘比例；有用戶端重設資料時顯示倒數。
- **點開查看詳細資訊**：方案名稱、剩餘／已用／總量、上傳和下載、預計重設日期、方案到期日期，以及來源與更新時間。
- **多個訂閱，各自清楚**：自動尋找可讀取的用戶端訂閱，也可手動加入 HTTPS 訂閱連結，切換查看對應數據。
- **適度的提醒**：剩餘不足 20% 時以橘色提醒，不足 10% 時以紅色提醒；流量不足或用盡也有文字說明，不只依賴顏色。
- **原生 macOS 體驗**：SwiftUI、淺色／深色外觀、等寬數字、減少動態效果支援，以及明確標示開啟／關閉狀態的登入時啟動控制。
- **五種介面語言**：簡體中文、繁體中文、英文、韓文和日文。

字節貓糧**不是代理用戶端、VPN、測速工具或逐一統計 App 流量的工具**。它不會代替 Clash／Mihomo 路由網路，也不會改變服務商的方案額度。

## 顏色與進度怎麼讀

| 剩餘流量占比 | 顯示 | 意義 |
| --- | --- | --- |
| ≥20% | 隨外觀變化的黑／白主色 | 正常 |
| ≥10% 且 <20% | 橘色 | 流量不足 |
| <10% | 紅色 | 流量嚴重不足或已用盡 |

選單列圓餅圖表示**剩餘比例**；詳細資訊卡片的橫向進度條表示**已用比例**，與「已用」百分比一致。警告色只表示流量風險，不代表方案等級、連線狀態或是否啟用自動啟動；接近重設日期本身也不是故障。

## 訂閱從哪裡來

**目前版本相容範圍（build 49）**：自動探索與手動匯入是兩種不同能力。Stash、Clash、Surge、Hiddify、Loon、sing-box 的受支援匯入連結可直接貼上，App 僅在本機擷取其中的 HTTPS 訂閱網址；Quantumult／Quantumult X 可手動加入原始 HTTPS 訂閱。服務商須回傳 `Subscription-Userinfo` 或受支援的 Shadowsocks SIP008 流量欄位。未新增這些用戶端的自動探索，也未宣稱完成所有用戶端／服務商聯測。[詳細格式與官方依據](docs/client-compatibility.md)。

| 來源／用戶端 | 讀取或匯入方式 | 說明 |
| --- | --- | --- |
| Clash Verge／Clash Verge Rev | 本機 `profiles.yaml` 中的訂閱連結 | 查詢服務商回傳的流量資訊 |
| ClashX／ClashX Meta／ClashX Pro | 用戶端偏好設定中的訂閱連結 | 取決於用戶端是否儲存了可讀取的設定 |
| 守候網路（SNTP） | 訂閱連結、方案和流量快取、用戶端回報的重設天數 | 快取可能沒有可信的原始更新時間 |
| 手動加入 | 貼上的 HTTPS 訂閱連結 | 服務商需提供可解析的流量資訊 |
| Stash／Clash | 手動貼上 HTTPS 訂閱或受支援的 `install-config` 連結 | Stash 另支援指定格式的 `link.stash.ws` 設定連結 |
| Surge | HTTPS 訂閱、`#!MANAGED-CONFIG` 首行或設定匯入連結 | 不執行模組或設定內容 |
| Hiddify | HTTPS 訂閱或受支援的訂閱匯入連結 | 保留網址與權杖，不匯入單一節點 |
| Loon／sing-box | HTTPS 訂閱或受支援的訂閱／遠端設定匯入連結 | 不執行外掛、規則、腳本或用戶端控制動作 |
| Quantumult／Quantumult X | 手動貼上原始 HTTPS 訂閱 | 服務商需提供流量資訊 |
| Shadowsocks SIP008 | HTTPS 訂閱中的 `bytes_used`、`bytes_remaining` | 缺少上傳／下載拆分時顯示「— · 未提供」 |

單一 `ss://`、`vmess://`、`vless://`、`trojan://` 節點不是流量查詢介面。Shadowrocket 等未核實的專用連結不列為已支援；一般 VPN 帳戶餘額不在本次接入範圍。

即時數據來自訂閱請求的 `subscription-userinfo` 回應標頭，或無此標頭時的 SIP008 JSON 流量欄位。**使用 Mihomo 核心不代表支援自動探索**：自動探索針對上表的用戶端儲存格式，其他用戶端可嘗試手動加入連結。

字節貓糧不自行計量所有網路流量，數據以服務商／用戶端回傳值為依據。缺少流量標頭、重要欄位不完整、總額為零或查詢失敗時，不應把未知資料理解為「剩餘零」。使用舊數據時，請同時留意來源與更新時間。

### 重設與更新

- 缺少重設日時，可點「流量重設」卡片設定下次日期。手動日期只存本機，顯示「手動」及 `*`；清除後恢復訂閱資訊。過期顯示「日期已過」，不自動順延，也不會清零服務商流量。

- 重設天數由用戶端回報，不是一般訂閱回應標頭中的標準欄位。倒數與「預計」日期據此推算，**不是服務商確認的重設時刻**；舊快取可能影響準確性。
- 沒有重設資料時不猜測日期。方案到期與流量重設是兩個不同概念。
- App 執行時定期更新，也可手動更新；睡眠、網路與服務商回應可能造成延遲。
- 查詢會嘗試直接連線與常見本機代理連接埠（`7899`、`7890`、`7897`、`6152`），不會啟動代理用戶端或變更系統代理設定。

## 系統需求與安裝

需要 **macOS 13 或更新版本**。原生 Liquid Glass 樣式需要 macOS 26 或更新版本；舊系統使用相容樣式。安裝包支援的處理器架構、簽署與公證狀態，以對應版本說明為準。

從 [1.2.0（49）發布頁](https://github.com/mustundead/ByteKibble/releases/tag/v1.2.0-build49) 下載 DMG 或 ZIP。先結束舊版 App；開啟 DMG 後將 ByteKibble 拖到 Applications，或將 ZIP 解壓縮後移入「應用程式」。請從「應用程式」啟動，而非持續執行磁碟映像內的副本。首次使用會顯示歡迎頁。

本次二進位檔僅提供 **Apple silicon（arm64）**，不含 Intel 版本。本機建置、測試與介面檢查在 macOS 27 上完成；最低部署目標為 macOS 13，不代表所有舊系統均已實機驗證。

建議下載 `-installer.zip`：解壓縮後取得 DMG，並保留 App 主圖與右下角開盒子角標。直接透過 HTTP 下載 DMG 不會保留 Finder 自訂圖示的中繼資料，安裝內容相同。另一個 `-arm64.zip` 包含 App 本體。

![1.2.0（43）DMG 實際視窗](docs/assets/installer-1.2.0.png)

若 macOS 阻止開啟，請先核對下載來源、簽署與版本說明。僅在確認信任檔案時，依照 [Apple 官方說明](https://support.apple.com/guide/mac-help/mh40616/mac)，在「系統設定 → 隱私權與安全性」中處理。**簽署不等於已公證**，請勿為了安裝而關閉系統安全保護。

啟動後，請確認支援的用戶端已匯入訂閱，或在面板中加入 HTTPS 訂閱連結。App 在選單列中運作；登入時啟動是獨立選項，並非查看流量的必要條件。

## 隱私與界線

**解析在本機完成，不會將訂閱連結上傳至 MU Labs 或分析平台。** 用戶端設定識別、匯入連結擷取與流量欄位解析均在你的 Mac 上進行，不使用雲端分析或第三方訂閱轉換服務，也不執行訂閱中的腳本、規則或節點設定。

**本機解析不代表完全離線。** 重新整理流量需要請求訂閱服務商網址，並可能跟隨其 HTTPS 重新導向；服務商會收到請求所需的訂閱 URL／權杖。使用本機代理時，請求沿代理設定的路線傳送。檢查與下載更新會連線至 GitHub 及其下載服務，但更新器不接收訂閱連結、權杖或流量數據。關閉自動檢查更新不會停止流量重新整理。

目前原始碼（尚未發佈至安裝包）將手動連結存入本機鑰匙圈；偏好設定只保留名稱與雜湊識別碼，選取狀態與手動重置日期索引不再保存原始連結。舊記錄僅在鑰匙圈寫入及讀回驗證成功後遷移；失敗時保留舊記錄並提示，不宣稱已加密。歷史備份與其他用戶端設定不會被清理，亦不能保證裝置遭入侵後仍安全。已發佈的 build 49 仍以偏好設定保存手動連結。

目前原始碼保留系統 TLS 驗證，只允許同一 HTTPS 網域及連接埠的重新導向；跨網域連結須手動加入最終網址。取得流量標頭後停止下載本文；沒有流量標頭的 SIP008 本文上限為 2 MiB。只有暫時連線錯誤會嘗試其他本機代理路徑，HTTP、憑證及解析錯誤不會；自動重試採退避，手動重新整理仍可立即重試。介面不顯示可能含權杖的原始網路錯誤。

自動探索只讀取本機用戶端設定。加入、移除與復原只影響 App 自己的清單與手動連結儲存，**不修改或取消服務商訂閱**。

訂閱連結可能含有存取權杖，請像密碼一樣妥善保管。查詢會聯絡對應服務商；透過本機代理查詢時，請求沿該代理設定的路線傳送。字節貓糧沒有自己的流量中繼伺服器，也不會將訂閱連結傳送至分析平台。

回報問題時請遮蔽訂閱網址、權杖與帳戶資料，不要在公開 Issue 或截圖中貼上完整連結。

## 從原始碼建置

安裝包含 Swift 工具鏈的 Xcode 後：

```bash
git clone https://github.com/mustundead/ByteKibble.git
cd ByteKibble
swift build -c release
```

專案沒有第三方執行階段相依套件。以 `swift test -j 2` 執行測試；`bash scripts/package-local.sh release` 在 `output/acceptance/` 產生本機架構的 ad-hoc 簽署 App，需使用含 `actool` 的 Xcode。原始碼建置不會自動使用發布者的 Developer ID，也不會自動公證。DMG 打包方法見 [更新記錄](CHANGELOG.md)。
